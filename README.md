# «Доброе Сердце» — сайт приюта для животных. 

Учебный проект: адаптивный сайт на React + Vite, REST API на Express и база SQLite. В архиве оставлены исходники сайта и серверной части; материалы ТЗ и Figma-макеты не включены.

## Что есть в проекте
- Главная страница, каталог питомцев, карточка животного, форма заявки и страница 404.
- Поиск, фильтры, сортировка и пагинация каталога.
- REST API, база SQLite и seed-скрипт с демонстрационными питомцами.
- Форма заявки с проверкой данных на сервере.
- Вход администратора (JWT), управление карточками и заявками, загрузка фотографий, CSV-экспорт.
- Адаптивная вёрстка, переключение темы, слайдер и микроанимации.
- Локальные SVG-изображения, поэтому картинки не зависят от внешних фотохостингов.

## Требования
- Node.js 22.13 или новее и npm.
- Интернет при первом запуске для установки npm-зависимостей.

## Самый простой запуск в Windows
1. Распакуйте весь архив в отдельную папку.
2. Установите Node.js 22 LTS или новее, если он ещё не установлен.
3. Дважды нажмите `УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat`.
4. Дождитесь установки зависимостей и открытия `http://localhost:5173`.
5. Не закрывайте два окна сервера, пока пользуетесь сайтом.

Если автоматический запуск не сработал, выполните команды вручную.

**Backend** (первое окно CMD):
```bat
cd /d ПУТЬ\К\dobroe_serdtse_completeackend
copy .env.example .env
npm install
npm run seed
npm run dev
```

**Frontend** (второе окно CMD):
```bat
cd /d ПУТЬ\К\dobroe_serdtse_completerontend
copy .env.example .env
npm install
npm run dev
```

Откройте адрес Vite, обычно `http://localhost:5173`. Проверка API: `http://localhost:4000/api/health`.

## Структура
- `frontend/` — интерфейс React/Vite и локальные изображения.
- `backend/` — Express API, SQLite, авторизация, заявки и администрирование.
- `docs/План_тестирования.md` — список проверок перед демонстрацией.
- `docs/Сценарий_демо.md` — короткий сценарий показа проекта.
- `scripts/check-imports.mjs` — проверка относительных импортов.

## Проверки
Из корня проекта:
```bat
node scripts/check-imports.mjs
```
В `backend`:
```bat
npm test
node --check src/server.js
```
В `frontend`:
```bat
npm run build
```

## Основные API-маршруты
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка API |
| GET | `/api/animals` | Каталог, фильтры и пагинация |
| GET | `/api/animals/:id` | Карточка питомца |
| POST | `/api/applications` | Отправка заявки |
| POST | `/api/auth/login` | Вход администратора |
| GET/POST | `/api/admin/animals` | Просмотр и создание питомцев (JWT) |
| PATCH/DELETE | `/api/admin/animals/:id` | Изменение и удаление питомца (JWT) |
| GET | `/api/applications` | Просмотр заявок (JWT) |
| PATCH | `/api/applications/:id` | Изменение статуса заявки (JWT) |
| GET | `/api/admin/applications.csv` | Экспорт заявок (JWT) |
