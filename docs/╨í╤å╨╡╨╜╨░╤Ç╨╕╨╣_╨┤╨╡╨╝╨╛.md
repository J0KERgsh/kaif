# Сценарий записи демонстрации (45–60 секунд)

1. **0–8 с:** открыть главную страницу, показать hero и слайдер животных.
2. **8–18 с:** перейти в каталог, ввести часть имени, показать фильтры и карточки.
3. **18–28 с:** открыть карточку питомца, показать статус, описание и кнопку заявки.
4. **28–38 с:** показать форму заявки и её клиентскую валидацию (не отправлять настоящие персональные данные).
5. **38–50 с:** открыть админ-панель, войти демо-аккаунтом, показать таблицу и изменение статуса.
6. **50–60 с:** показать мобильную ширину браузера и адаптивную навигацию.

Перед записью убедитесь, что frontend и backend запущены. В видео не показывайте настоящие пароли, персональные данные или секреты из `.env`.
