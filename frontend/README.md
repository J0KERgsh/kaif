# Frontend — «Доброе Сердце»

React + Vite SPA для приюта животных. Включает главную страницу, каталог, детальную карточку, форму усыновления, админ-панель и 404.

## Запуск
```bash
npm install
cp .env.example .env
npm run dev
```
В Windows CMD команда копирования: `copy .env.example .env`. По умолчанию API ожидается на `http://localhost:4000`; адрес можно изменить в `VITE_API_URL`.

## Сборка
```bash
npm run build
npm run preview
```

## Возможности
- Каталог из API: поиск, фильтры по виду/полу/возрасту/статусу, сортировка, пагинация.
- Динамические страницы `/animals/:id` и `/adopt/:id`.
- Загрузка и отображение локальных SVG-иллюстраций и фото с API `/uploads`.
- Адаптивная навигация, хлебные крошки, страница 404.
- Слайдер, скелетоны, scroll reveal, `prefers-reduced-motion`.
- Переключение светлой/тёмной темы с сохранением в `localStorage`.

## Деплой
`vercel.json` и `netlify.toml` содержат SPA fallback для прямого открытия динамических маршрутов. При публикации обязательно установите `VITE_API_URL` в URL опубликованного backend.
